# Prince Dhamsaniya — Developer Portfolio

> **Full-Stack Developer · MERN Stack · Software QA · UI/UX Design**  
> B.Tech Information Technology, Dharmsinh Desai University (D.D.U.), Nadiad, Gujarat.

A modern, high-performance developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion. Engineered with an editorial layout, clear visual hierarchy, multi-page routing, and a unified design system.

---

## ⚡ Tech Stack

* **Frontend Framework**: [React 18](https://react.dev/)
* **Build Tool**: [Vite](https://vitejs.dev/)
* **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
* **Motion & Interactions**: [Framer Motion](https://www.framer.com/motion/)
* **Icons**: [Lucide React](https://lucide.dev/)

---

## 🚀 Key Features

* **Dominant Full-Stack Identity**: Emphasizes MERN stack engineering with supporting areas in QA and UI/UX.
* **Editorial Hero Composition**: 2-column asymmetric layout with a dedicated portrait frame, monogram signature (`PD`), and interactive runtime console.
* **Featured Case Study Showcase**: Full-width browser case-study presentation for the Construction Management System, paired with secondary project cards.
* **Personal Story About Section**: Highlights technical background, academic credentials at D.D.U., and the **BUILD → TEST → DESIGN** methodology pipeline.
* **Dedicated Specialty Pages**:
  * `/#/projects`: Complete project showcase with category filtering (Full Stack, Frontend, UI/UX).
  * `/#/qa`: Testing workflow pipeline (Requirement → Test Design → Execution → Defect Log → Retest → Regression) and testing concepts.
  * `/#/ui-ux`: Case studies, design principles, and Figma deliverable badges.
  * `/#/resume`: Tailored resumes for Full-Stack Development, QA, and UI/UX.
* **Accessibility & Performance**: Keyboard accessible dialog modals, high-contrast typography, and `prefers-reduced-motion` compliance.

## 🛠️ Local Development

### 1. Clone the repository
```bash
git clone https://github.com/DhamsaniyaPrince/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```

## 📸 Profile Photo Customization

To personalize the portrait image:
1. Place your photo at:
   ```text
   src/assets/profile/profile-photo.png
   ```
2. The portfolio will automatically render your portrait inside the editorial hero frame.
